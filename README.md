# Hand-Gesture-Controller
This project presents an AI-based Hand Gesture based controller developed using Python, OpenCV, and MediaPipe. 

The system allows users to control the computer cursor, perform clicks, drag operations, and scroll using hand gestures captured through a webcam. 
The main objective of this project is to create a contactless and intelligent interface that can replace or assist traditional input devices.

The system uses computer vision techniques to detect hand landmarks in real time and applies gesture recognition logic to perform different mouse actions. 

This makes the system more interactive, efficient, and user-friendly. Such technology can be useful in touchless environments, smart systems, gaming, accessibility tools, and future human-computer interaction applications.

This project demonstrates the practical implementation of artificial intelligence, image processing, and gesture recognition to build a real-time virtual mouse control system with multiple features such as cursor movement, clicking, dragging, and scrolling.
